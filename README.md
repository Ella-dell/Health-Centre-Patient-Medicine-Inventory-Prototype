# Health-Centre-Patient-Medicine-Inventory-Prototype
A beginner Python project for managing fictional patient records and monitoring medicine inventory, created as part of my self-directed programming practice.
## About the Project
I created this project while learning Python independently. It is a simple prototype inspired by my interest in using software to improve healthcare record management and medicine inventory tracking.
The project demonstrates how basic Python concepts can be used to organize information and automate simple tasks.
## Features
- Patient lookup using fictional sample records stored in a Python dictionary
- Medicine inventory tracking
- Low-stock detection and warnings
- User input and conditional logic
## Python Concepts Practiced
- Dictionaries
- User input
- `if/else` statements
- `for` loops
- String methods
- Basic data organization
## How It Works
The program allows the user to enter a patient ID and retrieve the corresponding record. It also displays medicine inventory and identifies medicines whose stock falls below the defined minimum level.
## Project Status
This is a beginner-level, self-directed learning project and is intended as a prototype rather than a production healthcare system.
Patient and inventory data are fictional and reset when the program closes; this prototype does not save them between runs.
